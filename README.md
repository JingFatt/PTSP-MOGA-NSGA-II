# PTSP-MOGA-NSGA-II
Period Travelling Salesman Problem (PTSP) with NSGA-II:

This project applies a Multi-Objective Genetic Algorithm (NSGA-II) to solve the Period Travelling Salesman Problem (PTSP) over a 7-day planning horizon. The goal is to generate optimized weekly routing plans that minimize total travel distance while balancing workload (demand) across days.

Key features include:

Problem formulation of PTSP with city coordinates, visit frequencies, and daily demand

Two-objective optimization: minimize distance and minimize daily demand imbalance

NSGA-II implementation with custom chromosome encoding, crossover, mutation, and non-dominated sorting

Visualization of:

Pareto fronts and hypervolume progression

Diversity and spread metrics

Sample daily tours for representative solutions

This repository is part of a master's-level project demonstrating the power of evolutionary algorithms in complex multi-day routing scenarios.
